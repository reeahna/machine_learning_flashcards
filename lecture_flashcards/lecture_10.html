Decision Trees: Basics & Visualization
▼
  • Decision Trees can perform classification, regression, and multi-output tasks. They are also the building blocks of Random Forests.
  • Scikit-Learn uses CART (Classification and Regression Trees) algorithm to train trees.
  • A tree node shows: the split condition, gini impurity, number of samples, value (class counts), and predicted class.
  • A pure node (gini = 0) contains only one class. A leaf node makes a final prediction.
  • Depth of the iris tree example: depth 0 = root (all 150 samples), depth 2 = leaf nodes.
  • Decision Trees require very little data preparation — no feature scaling needed.
📐
Impurity: Gini vs. Entropy
▼
  • Gini impurity: G_i = 1 − Σ p_{i,k}². Zero when node is pure.
  • Entropy: H_i = −Σ p_{i,k} log(p_{i,k}). Also zero when pure. Used as alternative criterion.
  • Both lead to similar trees. Gini is faster. Entropy tends to produce slightly more balanced trees.
  • CART chooses the split (feature k, threshold t_k) that minimizes the weighted impurity of the two child nodes.
  • CART cost: J(k, t_k) = (m_left/m)·G_left + (m_right/m)·G_right
Gini impurity
G_i = 1 − Σ p_{i,k}²
CART classification cost
J(k,t_k) = (m_left/m)·G_left + (m_right/m)·G_right
⚙️
CART Algorithm & Complexity
▼
  • CART is a greedy algorithm: finds the optimal split at the top then repeats at each level. Does not check whether a split leads to the lowest impurity several levels down.
  • Finding the optimal tree is NP-Complete — O(exp(m)). The greedy approach produces a good but not necessarily optimal solution.
  • CART stops when it reaches max_depth or cannot find a split that reduces impurity.
  • Prediction time complexity: O(log m). Training complexity: O(n·m·log m) (n = features, m = instances).
  • Decision Trees make orthogonal decision boundaries — all splits are perpendicular to a feature axis. This makes them sensitive to feature rotation.
✂️
Regularization & Overfitting
▼
  • Decision Trees are nonparametric models — structure is not fixed prior to training, so they can overfit.
  • Key regularization hyperparameters: max_depth, min_samples_split, min_samples_leaf, max_leaf_nodes, max_features.
  • Increasing min_samples_* or decreasing max_depth regularizes (reduces overfitting).
  • Decision Trees are very sensitive to small variations in training data — removing one instance can produce a completely different tree.
  • This instability is why Random Forests work — they average over many trees trained on different subsets.
📉
Decision Tree Regression
▼
  • DecisionTreeRegressor: CART works the same way but minimizes MSE instead of impurity.
  • A leaf node predicts the mean value of all training instances in that node.
  • CART regression cost: J(k, t_k) = (m_left/m)·MSE_left + (m_right/m)·MSE_right
  • Regression trees are also prone to overfitting — use min_samples_leaf to regularize.
