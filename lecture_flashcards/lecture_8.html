What is Softmax Regression?
▼
  • Softmax Regression (Multinomial Logistic Regression): a generalization of Logistic Regression that directly supports multiple classes without needing to combine multiple binary classifiers.
  • For each instance, it computes a score sₖ(x) for each class k, then applies the softmax function to get class probabilities.
  • Each class k has its own dedicated parameter vector θ⁽ᵏ⁾. All parameter vectors are stored as rows in a parameter matrix Θ.
  • Score equation: sₖ(x) = (θ⁽ᵏ⁾)ᵀ x — just like linear regression prediction, one per class.
Score for class k
sₖ(x) = (θ⁽ᵏ⁾)ᵀ x
Generalizes Logistic Regression to K classes
📐
Softmax Function & Prediction
▼
  • The softmax function (also called normalized exponential) converts raw scores into class probabilities. Each output is between 0 and 1, and all outputs sum to 1.
  • Prediction: The class with the highest estimated probability (= highest score) is predicted.
  • The scores are also called logits or log-odds.
  • Multiclass, not multioutput: Softmax predicts exactly one class at a time. It should only be used with mutually exclusive classes (e.g. different types of plants — not multiple people in a photo).
  • Decision boundaries between any two classes are linear.
  • A model can predict a class with estimated probability below 50% (if all other classes have even lower probabilities).
Softmax function (probability for class k)
p̂ₖ = σ(s(x))ₖ = exp(sₖ(x)) / Σⱼ₌₁ᴷ exp(sⱼ(x))
Softmax prediction rule
ŷ = argmax_k σ(s(x))ₖ = argmax_k sₖ(x) = argmax_k (θ⁽ᵏ⁾)ᵀx

K = number of classes. s(x) = vector of scores for each class. argmax returns the class k with the highest score.

Both equations — know them

Cross-Entropy Cost Function
▼
  • Training objective: model should estimate high probability for the target class and low probabilities for others.
  • Cost function is called cross-entropy — a generalization of log loss to K classes.
  • Cross-entropy penalizes the model when it estimates a low probability for the target class.
  • The likelihood for one data point: L = Π_{k=1}^{K} pₖ^{yₖ}. Taking negative log-likelihood gives the cross-entropy cost.
  • Training is done with Gradient Descent (no closed-form solution).
  • Cross-entropy information theory origin: Measures the average number of bits needed to send information about the true distribution using the model's predicted distribution. KL divergence measures the extra cost from wrong assumptions.
Cross-entropy cost function
J(Θ) = −(1/m) Σᵢ₌₁ᵐ Σₖ₌₁ᴷ yₖ⁽ⁱ⁾ log(p̂ₖ⁽ⁱ⁾)

yₖ⁽ⁱ⁾ = 1 if instance i belongs to class k, else 0 (one-hot). p̂ₖ⁽ⁱ⁾ = estimated probability for class k for instance i. Reduces to binary cross-entropy when K=2.
