K-Means Algorithm
▼
  • K-Means assigns each instance to the nearest centroid (cluster center) iteratively.
  • Algorithm: (1) Initialize k centroids randomly. (2) Label each instance with its nearest centroid. (3) Update centroids to be the mean of their assigned instances. (4) Repeat until centroids stop moving.
  • Guaranteed to converge in a finite number of steps, but may not find the optimal solution.
  • Hard clustering: each instance is assigned to exactly one cluster.
  • Soft clustering: each instance gets a score per cluster (e.g., distance to centroid). Use the transform() method in KMeans.
🎲
Centroid Initialization
▼
  • Random initialization can lead to bad solutions (local minima).
  • Mitigation strategies: run the algorithm multiple times with different random seeds and keep the best (lowest inertia) solution.
  • K-Means++: smarter initialization — pick first centroid randomly, then each subsequent centroid is chosen with probability proportional to its squared distance from the nearest already-chosen centroid.
  • K-Means++ greatly reduces the chance of bad initialization and is the default in Scikit-Learn.
📏
Finding Optimal k: Elbow & Silhouette
▼
  • Inertia: mean squared distance from each instance to its closest centroid. NOT a good metric for choosing k — keeps decreasing as k increases.
  • Elbow method: plot inertia vs. k; look for the elbow where inertia stops decreasing sharply.
  • Silhouette coefficient for an instance: (b − a) / max(a, b), where a = mean intra-cluster distance, b = mean nearest-cluster distance.
  • Silhouette ranges from −1 to +1. Close to +1: well-placed. Close to 0: near boundary. Close to −1: likely in wrong cluster.
  • Silhouette score: mean silhouette coefficient over all instances. Better metric than inertia for choosing k.
Silhouette coefficient
(b − a) / max(a, b)
a = mean distance to same-cluster instances, b = mean distance to nearest-cluster instances
🔧
K-Means Applications
▼
  • Image segmentation: cluster pixels by color, then replace each pixel with its centroid color.
  • Preprocessing: use K-Means to reduce a high-dimensional input into k distance features. Can improve classification performance.
  • Semi-supervised learning: label a small set of representative instances (one per cluster centroid) and propagate labels to nearby instances.
  • Limitations: K-Means assumes roughly spherical, equal-size clusters. Struggles with elongated or different-density clusters.
