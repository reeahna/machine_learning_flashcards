Convolutional Layers
▼
  • Convolutional layer: the most important building block of a CNN. Neurons are connected only to a small region of the previous layer called the receptive field — not every pixel.
  • This allows early layers to detect low-level features (edges), and later layers to combine them into high-level features (faces, objects) — hierarchical feature detection.
  • A filter (kernel) slides across the input and produces one feature map.
  • Parameter sharing: all neurons in a given feature map share the same weights and bias. Neurons in different feature maps have different parameters.
  • Stride: the shift between adjacent receptive fields. Stride > 1 reduces the spatial dimensions of the output.
  • Zero padding: adding zeros around the input so a layer can have the same height and width as the previous layer ('same' padding).
📦
Feature Maps & Stacking
▼
  • A single convolutional layer outputs one feature map per filter. The number of filters is a hyperparameter.
  • All neurons in a feature map share weights → the filter detects the same feature regardless of location (translation invariance).
  • Multiple stacked convolutional layers allow progressively more abstract feature detection.
  • Memory: a 5×5 filter, 200 feature maps, 150×100 RGB input → 15,200 parameters but 225 million multiplications per instance.
  • If training crashes due to OOM: reduce mini-batch size, stride, or use fewer filters.
Parameter count for conv layer
(f_h × f_w × channels + 1) × n_filters
The +1 is for the bias term
🔽
Pooling Layers
▼
  • Pooling layers: reduce spatial dimensionality of feature maps — reducing computation and providing a form of translation invariance.
  • Max pooling: takes the maximum value in each pooling window. Most common.
  • Average pooling: takes the mean. Used in some architectures (e.g., global average pooling in ResNet).
  • Pooling slides a window over the feature map with a given stride.
  • Pooling is applied independently to each feature map.
🏛️
Famous CNN Architectures
▼
  • LeNet-5 (1998): pioneer architecture for handwritten digit recognition. Uses 5×5 filters, avg pooling, tanh activations.
  • AlexNet (2012): won ILSVRC with 17% top-5 error (2nd place: 26%). Introduced ReLU activations, dropout, data augmentation at scale.
  • GoogLeNet (2014): below 7% top-5 error. Key innovation: Inception modules — parallel filters of different sizes processed simultaneously.
  • ResNet (2015): 152 layers, under 3.6% top-5 error. Key innovation: skip connections (shortcut connections) — input is added to output of a layer stack.
  • ResNet skip connections allow the network to learn residual functions. Network can make progress even if some layers have not learned yet.
🔁
Transfer Learning & Localization
▼
  • Transfer learning: reuse lower layers of a pretrained model (e.g., Xception, ResNet-50) trained on ImageNet for a new task.
  • Freeze pretrained weights first, train top layers. Then unfreeze with a lower learning rate.
  • ResNet-50 expects 224×224 pixel images. Use preprocess_input() for each architecture.
  • Object localization: regression task — predict bounding box (x, y, height, width) = 4 numbers. Use MSE loss.
  • Typical CNN architecture: Conv+ReLU → Pool → Conv+ReLU → Pool → Fully Connected → Softmax.
