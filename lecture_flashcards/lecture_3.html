The 8-Step ML Project Workflow
▼
  • 1. Look at the big picture — frame the problem, define the objective, choose a performance measure.
  • 2. Get the data — collect and load your dataset.
  • 3. Discover and visualize the data — explore distributions, correlations, and patterns.
  • 4. Prepare the data — clean, impute missing values, scale features, encode categories.
  • 5. Select and train a model — try several algorithms, evaluate with cross-validation.
  • 6. Fine-tune the model — tune hyperparameters (Grid Search, Random Search).
  • 7. Present the solution — communicate results clearly.
  • 8. Launch, monitor, and maintain — deploy and watch for model degradation.

Framing the Problem (Real Estate Example)
▼
  • The running example is predicting median housing price by district to decide whether to invest.
  • Three framing questions to always ask: Is it supervised, unsupervised, or RL? Is it classification or regression? Batch or online learning?
  • This is a supervised regression problem — labeled data (known prices), continuous output.
  • Data snooping bias: never look at the test set before training. If you explore it, your intuitions get biased by it.

Performance Measures — RMSE and MAE
▼
  • RMSE (Root Mean Square Error) — the typical performance measure for regression. Uses the Euclidean (ℓ₂) norm. More sensitive to outliers because errors are squared.
  • MAE (Mean Absolute Error, also called average absolute deviation) — uses the Manhattan (ℓ₁) norm. Preferred when there are many outliers.
  • The higher the norm index, the more it focuses on large errors and neglects small ones.
  • When outliers are exponentially rare (bell-shaped distribution), RMSE performs well and is generally preferred.
RMSE equation (Euclidean / ℓ₂ norm)
RMSE(X, h) = √( (1/m) Σᵢ₌₁ᵐ (h(x⁽ⁱ⁾) − y⁽ⁱ⁾)² )
MAE equation (Manhattan / ℓ₁ norm)
MAE(X, h) = (1/m) Σᵢ₌₁ᵐ |h(x⁽ⁱ⁾) − y⁽ⁱ⁾|

m = number of instances. h = hypothesis/prediction function. x⁽ⁱ⁾ = feature vector of instance i. y⁽ⁱ⁾ = true label of instance i. ŷ⁽ⁱ⁾ = h(x⁽ⁱ⁾) = predicted value.

Data Preparation
▼
  • Handling missing values: drop the attribute, drop the rows, or impute (fill with median/mean/zero). SimpleImputer in sklearn handles this.
  • Feature scaling is one of the most important transformations — ML algorithms struggle when features have very different scales.
  • Min-max scaling (normalization): rescales values to [0, 1] by subtracting min and dividing by (max − min). Sensitive to outliers.
  • Standardization (z-score): subtracts the mean, divides by standard deviation. Result has zero mean and unit variance. Much less affected by outliers.
Min-max scaling formula
x_scaled = (x − min) / (max − min)
Standardization (z-score) formula
x_standardized = (x − μ) / σ

μ = mean of the feature. σ = standard deviation. Standardization is preferred when outliers are present.

Model Selection & Fine-Tuning
▼
  • Cross-validation: splits the training set into K folds; trains on K−1 folds and evaluates on the remaining fold, repeated K times. Gives a better estimate of model performance than a single validation split.
  • Grid Search: tries all combinations of specified hyperparameter values. Exhaustive but slow.
  • Random Search: samples hyperparameter combinations randomly. Better when the search space is large.
  • Fine-tuning should always be done on the training/validation set only — not the test set.
  • After all tuning is done, evaluate once on the test set for the final unbiased estimate.
