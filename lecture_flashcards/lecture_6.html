Polynomial Regression
▼
  • Polynomial Regression: Uses a linear model to fit non-linear data by adding powers of features as new features (e.g. adding x² as a feature).
  • Despite fitting non-linear data, it is still a linear model because it is linear in the parameters.
  • High-degree polynomial regression will likely overfit; low-degree linear regression will likely underfit.
  • Learning curves plot training and validation error as a function of training set size. Used to diagnose overfitting vs. underfitting.
  • Underfitting signature: Both curves plateau high and close together.
  • Overfitting signature: Large gap between training error (low) and validation error (high). Adding more training data closes this gap over time.
Learning curve patterns — know both
🔒
Ridge Regression (L2 Regularization)
▼
  • Ridge Regression (also called Tikhonov regularization): adds a regularization term (½ α Σθⱼ²) to the cost function. Uses the ℓ₂ norm of the weights.
  • Forces the learning algorithm to keep weights small as well as fit the data.
  • If α is very large, all weights end up close to zero → flat line through the data mean.
  • α is a hyperparameter that controls how much regularization is applied.
  • Regularization term is applied during TRAINING only, not at test time.
Ridge cost function
J(θ) = MSE(θ) + α × (1/2) Σⱼ₌₁ⁿ θⱼ²

α controls regularization strength. Sum starts from j=1 (bias term θ₀ is not regularized). Uses ℓ₂ norm (squared weights).

Equation — know itℓ₂ norm
🔪
Lasso Regression (L1 Regularization)
▼
  • Lasso Regression (Least Absolute Shrinkage and Selection Operator): uses the ℓ₁ norm of the weight vector instead of ½ the ℓ₂ norm.
  • Key property: Lasso tends to reduce the weights of useless features all the way to zero, effectively performing automatic feature selection.
  • Can behave erratically when the number of features is greater than the number of training instances or when features are highly correlated.
Lasso cost function
J(θ) = MSE(θ) + α Σⱼ₌₁ⁿ |θⱼ|

Uses ℓ₁ norm (absolute values of weights). Tends to produce sparse models (many weights = 0).

ℓ₁ norm — sparse weights
⚖️
Elastic Net & When to Use Each
▼
  • Elastic Net: Middle ground between Ridge and Lasso. Mixes both regularization terms, controlled by ratio r.
  • When r=0 → equivalent to Ridge. When r=1 → equivalent to Lasso.
  • Which to use?
  • Avoid plain Linear Regression (no regularization) — almost always better to have some regularization.
  • Ridge is a good default.
  • Prefer Lasso or Elastic Net if you suspect only a few features are useful (they zero out useless features).
  • Prefer Elastic Net over Lasso when features > instances or when features are highly correlated (Lasso may behave erratically).
Know when to use Ridge vs Lasso vs Elastic Net
🛑
Early Stopping
▼
  • Early stopping: Stop training as soon as the validation error reaches a minimum. A very different form of regularization for iterative learning algorithms.
  • With Stochastic/Mini-batch GD, the curves are not smooth, so stop only after validation error has been above the minimum for some time, then roll back to the minimum point.
