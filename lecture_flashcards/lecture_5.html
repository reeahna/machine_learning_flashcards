Linear Regression Model & Normal Equation
▼
  • Linear Regression models a linear relationship between inputs and a continuous output.
  • Two training approaches: (1) closed-form Normal Equation, (2) iterative Gradient Descent.
  • Normal Equation: Directly computes the θ that minimizes MSE. No iteration needed.
  • SVD approach: An alternative closed-form method using Singular Value Decomposition.
  • Limitation of Normal Equation: Gets very slow when the number of features grows large (e.g. 100,000+). Both Normal Equation and SVD are O(m) with respect to instances but slow with many features.
Linear regression model
ŷ = θ₀ + θ₁x₁ + θ₂x₂ + ... + θₙxₙ = θᵀx

ŷ = predicted value. θ₀ = bias term. θ₁...θₙ = feature weights. x₁...xₙ = feature values. n = number of features.

Equation — know it
📉
MSE Cost Function
▼
  • Training objective: find θ that minimizes the Mean Squared Error (MSE) cost function.
  • In practice, we minimize MSE rather than RMSE because they have the same minimum and MSE is easier to compute derivatives for.
  • The MSE cost function for linear regression is convex — no local minima, just one global minimum. Gradient Descent is guaranteed to find it.
  • Feature scaling is important for GD convergence: without it the cost function is elongated and takes much longer to converge.
MSE cost function
MSE(θ) = (1/m) Σᵢ₌₁ᵐ (θᵀx⁽ⁱ⁾ − y⁽ⁱ⁾)²
Convex — one global minimum
⛰️
Gradient Descent & Learning Rate
▼
  • Gradient Descent: Generic optimization algorithm that iteratively tweaks parameters in the direction of steepest descent to minimize a cost function.
  • Learning rate (η): Controls the step size. Too small = very slow convergence. Too large = may diverge (jump past the minimum).
  • Stop when the gradient vector becomes tiny.
  • GD requires features to have similar scale — otherwise the cost function is elongated and takes much longer.
Gradient Descent update rule
θ⁽ⁿᵉˣᵗ ˢᵗᵉᵖ⁾ = θ − η∇θ MSE(θ)

η = learning rate. ∇θ MSE(θ) = gradient vector of the cost function (points uphill). We subtract it to go downhill.

η too small = slow. η too large = diverge.
🔀
Batch, Stochastic & Mini-batch GD
▼
  • Batch Gradient Descent: Computes gradients using the FULL training set at every step. Very slow on large datasets. Guaranteed to reach the global minimum (for convex functions).
  • Stochastic Gradient Descent (SGD): Picks ONE random instance per step. Much faster per step, but bounces around. Can escape local minima. Training instances must be IID (shuffled). Settles near but not exactly at the global minimum.
  • Mini-batch GD: Computes gradients on small random subsets (mini-batches). Main advantage over SGD: hardware optimization (GPU speedup) for matrix operations.
  • SGD requires shuffling instances to ensure IID — otherwise GD optimizes for one label at a time.
Know all three differences
