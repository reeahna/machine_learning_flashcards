Gaussian Mixture Models
▼
  • A Gaussian Mixture Model (GMM) is a probabilistic model assuming instances come from a mixture of several Gaussian distributions with unknown parameters.
  • Parameters per Gaussian: mean (μ), covariance (Σ), and mixing weight (φ — probability of being generated by that Gaussian).
  • GMMs are a form of soft clustering: each instance has a probability of belonging to each Gaussian component.
  • Used for: clustering, density estimation, anomaly detection.
🔄
EM Algorithm
▼
  • EM (Expectation-Maximization): iterative algorithm to fit GMMs to data with unknown assignments.
  • E-step (Expectation): estimate which Gaussian each data point came from — compute the probability of each hidden variable (cluster assignment) given current parameters.
  • M-step (Maximization): given the soft cluster assignments, update the Gaussian parameters (mean, covariance, mixing weights) to maximize likelihood.
  • Repeat E and M steps until convergence.
  • Similarities to K-Means: random initialization, alternating assignment/update steps, converges to a local optimum.
📐
Selecting Number of Clusters
▼
  • For Gaussian mixtures, inertia and silhouette score are NOT reliable when clusters are non-spherical or have different sizes.
  • BIC (Bayesian Information Criterion) and AIC (Akaike Information Criterion): theoretical information criteria that penalize model complexity.
  • Lower BIC/AIC is better. Use these to select k for GMMs.
  • BIC penalizes complexity more than AIC — tends to select simpler models.
BIC
BIC = log(m)·p − 2·log(L̂)
p = number of parameters, L̂ = maximized likelihood; lower is better
🚨
GMM for Anomaly Detection
▼
  • A GMM can estimate the density of the dataset at any point.
  • Instances in low-density regions are considered anomalies.
  • Threshold: any instance with score below a density threshold is flagged as an anomaly.
  • This is an example of novelty detection or anomaly detection using a generative model.
