🌲
Ensemble Learning & Voting
▼
  • Ensemble Learning: aggregating predictions from a group of predictors (classifiers or regressors) typically gives better results than any single predictor.
  • Hard voting: predict the class that gets the most votes across predictors.
  • Soft voting: average the predicted class probabilities (requires predict_proba). Often outperforms hard voting.
  • Ensembles work best when predictors are diverse and independent.
  • People often use ensembles near the end of a project to combine several good predictors.
🎒
Bagging & Pasting
▼
  • Bagging (bootstrap aggregating): train each predictor on a random subset of training data sampled with replacement.
  • Pasting: same but sampled without replacement.
  • Each predictor sees a different subset, so they make different errors — aggregation reduces variance.
  • Net effect: ensemble has similar bias but lower variance than a single predictor trained on the full set.
  • Out-of-bag (OOB) evaluation: with bagging, ~37% of instances are never sampled. These can be used for evaluation without a separate validation set. Set oob_score=True in Scikit-Learn.
🌳
Random Forests
▼
  • Random Forest: an ensemble of Decision Trees trained via bagging, typically with max_samples set to training set size.
  • Extra randomness: at each node, only a random subset of features is considered for splitting (max_features hyperparameter). This decorrelates the trees.
  • Feature importance: Random Forests measure importance by how much tree nodes using that feature reduce impurity on average (across all trees). Very handy for feature selection.
  • Extra-Trees (Extremely Randomized Trees): uses random thresholds for each feature instead of searching for the best one. Even more random — lower variance but higher bias. Much faster to train.
⚡
Boosting
▼
  • Boosting: combines weak learners into a strong learner by training predictors sequentially, each correcting its predecessor.
  • AdaBoost: increases the weight of misclassified instances after each predictor, so the next predictor focuses on the hard cases. Predictors are combined using weighted voting.
  • Gradient Boosting: fits each new predictor to the residual errors of the previous predictor. Can use any differentiable loss function.
  • Gradient Boosting with too few trees: underfitting. Too many trees: overfitting the training set.
  • Use learning_rate to scale each tree's contribution. Small learning_rate + many trees = better but slower.
🔀
Stacking
▼
  • Stacking (stacked generalization): instead of using a voting function to aggregate predictions, train a blender (meta-learner) to perform the aggregation.
  • Hold-out set is used to train the blender on predictions of base predictors.
  • Can train multiple layers of blenders.
  • More flexible than voting but more complex to implement.
