🔧
Keras APIs
▼
  • Keras: a high-level deep learning API that runs on TensorFlow, CNTK, or Theano.
  • Sequential API: simplest — stack layers one by one. Good for most models. Limitation: single input, single output, no branching.
  • Functional API: more flexible — define layers as functions of other layers. Supports multiple inputs/outputs, skip connections, shared layers.
  • Subclassing API: most flexible — define custom forward pass logic in a call() method. Good for dynamic models. Downside: harder to inspect, save, or share.
  • Unless you need dynamic behavior, stick to Sequential or Functional API.
🏗️
Wide & Deep Architecture
▼
  • Wide path: connects some (or all) inputs directly to the output layer.
  • Deep path: passes through several hidden layers.
  • Result: the model can learn both simple rules (wide path) and complex patterns (deep path).
  • Implemented with the Functional API using multiple inputs feeding to different paths.
  • You can send different subsets of features through the wide vs. deep paths.
🔬
Hyperparameter Tuning
▼
  • Key hyperparameters: number of layers, neurons per layer, activation functions, weight initialization, learning rate, batch size, optimizer.
  • More neurons/layers = more capacity but also more overfitting risk and training time.
  • Number of hidden layers: lower layers learn simple patterns; higher layers combine them into complex patterns.
  • Increasing model capacity then regularizing is often a good strategy.
  • Use cross-validation, RandomSearchCV, or dedicated libraries (e.g., Keras Tuner) for hyperparameter search.
📤
Multiple Inputs & Outputs
▼
  • Functional API supports models with multiple inputs (e.g., features split between wide and deep paths).
  • Multiple outputs can be useful: (1) locate AND classify an object, (2) auxiliary outputs as a regularization technique to ensure subparts of the network learn useful representations.
  • Subclassing API allows fully dynamic models (loops, conditional branching) but loses inspectability.
  • The summary() method with Subclassing API only shows layers without connection info.
