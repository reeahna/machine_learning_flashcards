Large Margin Classification & Support Vectors
▼
  • SVM fits the widest possible "street" between classes — this is called large margin classification.
  • Decision boundary: wᵀx + b = 0. Margins (support vector boundaries): wᵀx + b = ±1.
  • Support vectors: The instances that sit exactly on the edge of the margin. The decision boundary is entirely determined by them — adding more instances off the street doesn't change it.
  • To maximize the margin, we minimize ‖w‖ (the norm of the weight vector). Distance between each margin and the decision boundary = 1/‖w‖.
  • SVMs are sensitive to feature scaling. Always scale features before using an SVM.

Hard Margin vs. Soft Margin
▼
  • Hard margin: All instances must be off the street and on the right side. Two problems: (1) only works if data is linearly separable, (2) very sensitive to outliers.
  • Soft margin: Balances keeping the street as wide as possible while allowing some margin violations. Controlled by hyperparameter C.
  • C hyperparameter: Small C = wider margin, more violations allowed (more regularization). Large C = narrower margin, fewer violations (less regularization, risk of overfitting).
  • If overfitting, reduce C. If underfitting, increase C.
  • Slack variable ζ (zeta) ≥ 0: measures how much each instance is allowed to violate the margin.
  • The primal objective balances minimizing ‖w‖ (large margin) and reducing margin violations (via C and ζ).
C controls trade-off — know the direction

Kernel Trick & Kernels
▼
  • Nonlinear SVM: Adding polynomial features can make non-linearly separable data linearly separable — but can cause feature explosion.
  • Kernel trick: Computes dot products in a transformed feature space without actually transforming the data. Mathematically equivalent but computationally efficient.
  • A kernel is a function capable of computing φ(a)ᵀφ(b) based only on original vectors a and b, without computing or knowing the transformation φ.
  • Polynomial kernel: K(a,b) = (γaᵀb + r)^d
  • Gaussian RBF kernel: K(a,b) = exp(−γ‖a−b‖²). γ acts like regularization: high γ = more complex boundary (overfitting risk), low γ = smoother boundary.
  • The dual problem makes the kernel trick possible. The primal problem does not.

Kernel Selection & LinearSVC vs. SVC
▼
  • Which kernel to use? Always try the linear kernel first — especially if training set is very large or has many features. Then try Gaussian RBF, which works well in most cases.
  • LinearSVC (liblinear library): No kernel trick. Scales almost linearly with instances and features. Fast for large datasets.
  • SVC (libsvm library): Supports kernel trick. Gets very slow when instances are numerous (hundreds of thousands). Best for complex small/medium datasets.
  • SVM Regression: Reversed objective — instead of fitting the widest street between classes, it tries to fit as many instances as possible ON the street while limiting margin violations. Street width controlled by hyperparameter ε (epsilon).
