Artificial Neural Networks
▼
  • ANN (Artificial Neural Network): network of artificial neurons inspired by biological neurons.
  • DNN (Deep Neural Network): ANN with multiple hidden layers.
  • MLP (Multi-Layer Perceptron): the simplest DNN — fully connected layers stacked on top of each other.
  • Each neuron computes: output = activation_function(Wx + b), where W = weights, b = bias.
  • The original perceptron used a step function. Modern neurons use differentiable activation functions (sigmoid, tanh, ReLU).
⚡
Activation Functions
▼
  • Activation functions must be differentiable so we can compute gradients during backpropagation.
  • Sigmoid: σ(z) = 1/(1 + exp(−z)). Outputs in (0,1). Used in output layers for binary classification.
  • Tanh: tanh(z) = 2σ(2z) − 1. Outputs in (−1,1). Centered around 0 — helps speed up convergence.
  • ReLU: ReLU(z) = max(0, z). No maximum output value — helps reduce vanishing gradient. Default for hidden layers.
  • Why non-linearity? Without it, chaining layers is equivalent to a single linear transformation — the network cannot solve complex problems.
  • A large enough DNN with nonlinear activations can approximate any continuous function (universal approximation theorem).

🔁
Backpropagation
▼
  • Backpropagation: for each training instance, (1) forward pass to make prediction and measure error, (2) backward pass to measure each connection's contribution to the error, (3) Gradient Descent step to update weights.
  • Uses the chain rule of calculus to efficiently compute gradients.
  • Weight update: θ ← θ − η∇θ MSE(θ), where η is the learning rate.
  • Requires differentiable activation functions at every layer.
🏗️
MLP Architecture Guidelines
▼
  • Input layer: one neuron per input feature (e.g., 784 for MNIST 28×28).
  • Hidden layers: typically 1 to 5 for regression; deeper for complex tasks.
  • Output layer: 1 neuron per output dimension (regression); 1 per class (multi-class with softmax).
  • Hidden activation: typically ReLU. Output activation: None (regression), Sigmoid (binary classification), Softmax (multi-class).
  • Loss function: MSE (regression), cross-entropy (classification).
