Types of Machine Learning
▼
  • Supervised: Training data has labels. Algorithms: Linear Regression, Logistic Regression, SVMs, k-NN, Decision Trees, Random Forests.
  • Unsupervised: No labels — finds structure on its own. Algorithms: K-Means, PCA, t-SNE, anomaly detection (Isolation Forest, One-class SVM).
  • Semisupervised: Lots of unlabeled + a small number of labeled examples.
  • Reinforcement Learning: Agent takes actions, gets rewards/penalties, learns a policy — the strategy for what action to take in each situation.

Batch vs. Online Learning
▼
  • Batch: Trains on ALL data at once. Cannot update incrementally. New data requires full retrain from scratch.
  • Online: Trains incrementally on instances individually or in minibatches. Learns on the fly as new data arrives.
📐
Instance-Based vs. Model-Based + Key Equation
▼
  • Instance-based: Memorizes examples. Generalizes by comparing new cases using a similarity measure. Classic example: k-NN.
  • Model-based: Builds a model with learned parameters and uses it to predict.

Main Challenges of ML
▼
  • Insufficient data: Quantity often matters more than algorithm choice (Banko & Brill, 2001).
  • Sampling bias: Nonrepresentative training data → poor generalization.
  • Poor quality data: Outliers and missing values hurt performance.
  • Irrelevant features ("garbage in, garbage out"): Feature engineering is critical.
  • Overfitting: Great on training data, poor on new data. Model too complex. Fix: regularization.
  • Underfitting: Poor even on training data. Model too simple. Fix: more complex model.

Testing, Validation & Hyperparameter Tuning
▼
  • Generalization error: Error on new, unseen cases. What matters in the real world.
  • Training set: Learn parameters from this.
  • Validation set: Tune and compare models during development.
  • Test set: Touched ONLY ONCE at the very end. Never use for tuning — repeated use = overfitting to the test set.
  • Regularization: Constrains/simplifies the model. Reduces overfitting. Does NOT increase complexity.
