What is Logistic Regression?
▼
  • Logistic Regression (also called Logit Regression): commonly used to estimate the probability that an instance belongs to a particular class.
  • It is a binary classifier: predicts 1 if estimated probability ≥ 50%, otherwise predicts 0.
  • Just like Linear Regression, it computes a weighted sum of input features plus a bias, but then runs the result through the logistic (sigmoid) function instead of outputting it directly.
  • The output is always between 0 and 1 — it is a probability.

Sigmoid Function & Prediction Rule
▼
  • The logistic/sigmoid function σ(t) = 1 / (1 + e⁻ᵗ) outputs a value between 0 and 1. It is S-shaped.
  • t = xᵀθ is called the logit (also called log-odds).
  • The logit function logit(p) = log(p / (1−p)) is the inverse of the sigmoid.
  • Prediction rule: ŷ = 0 if p̂ < 0.5; ŷ = 1 if p̂ ≥ 0.5. The decision boundary is where p̂ = 0.5 (i.e. t = 0).
Sigmoid (logistic) function
σ(t) = 1 / (1 + e⁻ᵗ)
Logistic regression probability estimate
p̂ = σ(xᵀθ) = 1 / (1 + exp(−xᵀθ))

Cost Function — Log Loss & Convexity
▼
  • The cost function for Logistic Regression is called log loss (negative log-likelihood / cross-entropy for binary classification).
  • Training objective: set θ so the model estimates high probabilities for positive instances and low probabilities for negative instances.
  • No closed-form solution (unlike Linear Regression) — there is no equivalent of the Normal Equation for Logistic Regression.
  • Good news: The cost function IS convex, so Gradient Descent is guaranteed to find the global minimum (given appropriate learning rate and enough time).
  • Maximum likelihood perspective: The log loss is equivalent to minimizing the negative log-likelihood, which is the cross-entropy loss for binary classification.
Log loss (binary cross-entropy)
J(θ) = −(1/m) Σ [y⁽ⁱ⁾ log(p̂⁽ⁱ⁾) + (1−y⁽ⁱ⁾) log(1−p̂⁽ⁱ⁾)]

y⁽ⁱ⁾ = true label (0 or 1). p̂⁽ⁱ⁾ = estimated probability. When y=1, cost = −log(p̂); when y=0, cost = −log(1−p̂).

No Normal Equation — must use GDConvex — one global minimum
🎯
Decision Boundaries & Maximum Likelihood
▼
  • The decision boundary is the set of points where p̂ = 0.5 (t = xᵀθ = 0). It is linear — Logistic Regression creates a linear decision boundary.
  • With two features, the decision boundary is a line; with more features, it's a hyperplane.
  • Maximum likelihood perspective: The likelihood of observing the data given the model parameters is L = p̂ʸ(1−p̂)^(1−y). Maximizing this (or minimizing negative log-likelihood) gives the same result as minimizing cross-entropy loss.
  • For N data points, minimizing the negative log-likelihood is exactly the cross-entropy loss function for binary classification.
