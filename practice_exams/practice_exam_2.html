Q1OverfittingMultiple Choice
A model achieves 99% training accuracy and 61% test accuracy. The best diagnosis is:
AData leakage — test labels leaked into training
BUnderfitting — the model is too simple
CSampling bias — the test set is unrepresentative
DHigh variance (overfitting) — the model memorized training patterns that do not generalize

Q2ValidationMultiple Choice
Why must hyperparameters be tuned on a validation set, not the test set?
AHyperparameter tuning requires labeled data the test set lacks
BThe test set uses a different loss function than validation
CThe test set is too small for reliable gradient estimates
DRepeated selection based on test performance makes the test effectively part of training, inflating generalization estimates
Every time you evaluate and adjust based on the test set, you are fitting to it. A separate validation set keeps the test set as a true measure of generalization.
Q3Softmax RegressionMultiple Choice
Cross-entropy loss for softmax regression is minimized when:
AThe predicted probability for the correct class is near 1
BAll class probabilities are equal
CThe softmax scores are all close to zero
DThe weight matrix has small Frobenius norm
Cross-entropy = -log(p̂ₖ) where k is the true class. Minimized (approaches 0) when p̂ₖ approaches 1. Maximized when the model is confident but wrong.
Q4Gradient DescentMultiple Choice
Mini-batch gradient descent (batch size 32-256) offers what main advantage over full-batch GD on large datasets?
AIt eliminates the need for a learning rate schedule
BIt has perfectly accurate gradient estimates using the full dataset
CIt always converges to a better solution
DIt provides reasonably accurate gradients efficiently, making better use of GPU hardware
Full batch is slow on large datasets. SGD (batch=1) is noisy. Mini-batches balance accuracy and efficiency, and GPU hardware is optimized for vectorized mini-batch operations.
Q5Confusion MatrixMultiple Choice
A false positive in binary classification is:
AA positive instance correctly classified as positive
BA positive instance incorrectly classified as negative
CA negative instance correctly classified as negative
DA negative instance incorrectly classified as positive
False positive: true label is negative but model predicted positive. Contributes to reduced precision. False negative: true positive predicted as negative, reducing recall.
Q6Gradient DescentMultiple Choice
Stochastic gradient descent (batch size = 1) can escape shallow local minima because:
AIts noisy single-instance gradient estimates can push parameters out of shallow minima that batch GD would get stuck in
BIt uses a smaller learning rate, making finer adjustments near minima
CIt computes a more accurate gradient by using all instances
DIt randomizes the activation function at each step
SGD gradient noise is useful — it can bounce parameters out of shallow local minima. Smooth batch GD follows the gradient exactly and may get stuck.
Q7Challenges of MLMultiple Choice
Collecting more training data most directly addresses which ML challenge?
AOverfitting due to insufficient training data
BUnderfitting from an overly simple model
CIrrelevant features reducing signal-to-noise ratio
DNon-representative sampling bias
More data helps the model generalize rather than memorize, directly combating overfitting. It does not fix underfitting, biased sampling, or noisy features.
Q8Data PreparationTrue / False

ATrue
BFalse
Stratified sampling preserves class ratios. Without it, rare classes may be underrepresented in the test set, leading to biased estimates.
Q9SVMsMultiple Choice
Maximizing the margin in SVMs (minimizing ||w||) produces models that:
AMaximize ||w|| — giving more weight to important features
BSet ||w|| = 1 as a normalization constraint
CCompute ||w|| as a function of support vector coordinates
DAre less sensitive to small perturbations in training data, reducing variance
A large margin means the boundary is far from all training instances. The classifier is robust to small perturbations — a new instance needs to be far from training data to be misclassified.
Q10RegularizationMultiple Choice
Early stopping is considered a regularization technique because:
AIt randomly drops units during training, reducing model capacity
BIt stops training before the model memorizes training-specific patterns
CIt adds noise to training, smoothing the loss landscape
DIt penalizes large weight values by adding them to the loss function
Early stopping monitors validation loss. When it starts increasing (overfitting begins), training stops. This limits effective model complexity without modifying the loss.
Q11Evaluation MetricsMultiple Choice
High precision and low recall on the positive class means:
AThe model is indiscriminate — predicts positive for almost every instance
BBoth precision and recall are dominated by the negative class
CWhen the model predicts positive it is usually right, but it misses many actual positives
DThe model predicts negative for almost every instance
Precision = TP/(TP+FP): when it predicts positive, it is correct. Recall = TP/(TP+FN): but it misses many actual positives. Example: a conservative cancer detector that rarely fires but is reliable when it does.
Q12Data PreparationMultiple Choice
Feature scaling is required for which algorithm?
ARandom Forests
BDecision Trees
CSVM with RBF kernel
DNaive Bayes
SVM with RBF kernel uses distances — sensitive to feature scale. Decision Trees, Random Forests, and most Naive Bayes variants are scale-invariant.
Q13Logistic RegressionMultiple Choice
σ(0) for the sigmoid function equals:
A0.25
B0
C0.5
D1.0
σ(z) = 1/(1+e⁻ᶻ). At z=0: 1/(1+1) = 0.5. The decision boundary where the model is maximally uncertain is where θᵀx = 0.
Q14Learning CurvesMultiple Choice
A learning curve showing high training error and similar high validation error indicates:
AHigh variance — adding more data will not help
BGood generalization — train and validation errors are close
COverfitting — the model is too complex
DUnderfitting — the model lacks capacity to capture the data patterns
When both errors are high and similar, the model underfits. Adding more data will not help. The fix is to increase model capacity.
Section B — Post-Midterm Material (Lectures 10–19)
Q15Neural NetworksMultiple Choice
Zero weight initialization causes training to fail because:
AAll neurons in each layer produce identical outputs and gradients, remaining identical forever — the symmetry problem
BZero weights cause numerical overflow in the first backward pass
CZero initialization prevents the loss from decreasing below a minimum
DZero weights force all activations to 0.5
Identical weights → identical activations → identical gradients → identical updates → weights stay identical. The network effectively has one neuron per layer. Random initialization breaks this symmetry.
Q16Neural NetworksMultiple Choice
ReLU is preferred over sigmoid in hidden layers primarily because:
AReLU outputs are bounded between 0 and 1, stabilizing training
BReLU is differentiable everywhere unlike sigmoid
CFor positive inputs, ReLU derivative = 1, avoiding vanishing gradients, and it is computationally cheap
DReLU automatically normalizes layer outputs
ReLU = max(0,z). Derivative = 1 for z > 0 — no gradient shrinking. Sigmoid derivative ≤ 0.25 — shrinks with depth. ReLU also avoids exponentiation.
Q17K-MeansMultiple Choice

AThe inertia value for the current clustering
BUpdated centroid positions after convergence
CA matrix of distances from each instance to each centroid
DPredicted cluster labels for each instance
transform() returns shape (m, k) — distances to each centroid. This converts instances into cluster-distance features, useful as input to a downstream classifier.
Q18CNNsMultiple Choice
ResNet's skip connections primarily solve:
AOverfitting by adding L2 regularization per residual block
BThe vanishing gradient problem by providing a direct gradient path through identity shortcuts
CHigh computational cost by skipping expensive layers during inference
DToo many parameters by sharing weights between alternate layers
F(x)+x means gradients flow directly through the identity shortcut during backpropagation, reaching early layers without vanishing. ResNet trained networks with 100+ layers successfully.
Q19Ensemble MethodsMultiple Choice

Q21CNNsMultiple Choice
Max pooling provides local translation invariance because:
AIt learns optimal downsampling weights via gradient descent
BIt normalizes feature map values to zero mean
CIt applies the same filter regardless of position
DIt retains the strongest activation in each window regardless of exact position within that window
If a feature shifts slightly, the max in that pooling window may not change. This robustness to small spatial shifts is local translation invariance.
Q22Neural NetworksMultiple Choice
The vanishing gradient problem in deep sigmoid/tanh networks occurs because:
AWeights grow too large, causing numerical overflow
BThe loss function is non-convex, trapping gradients in local minima
CBatch normalization clips gradients during backpropagation
DSigmoid/tanh derivatives are small (< 1), so gradients shrink exponentially as they propagate backward through many layers
During backpropagation, gradients multiply by activation derivatives at each layer. Sigmoid/tanh derivatives ≤ 0.25 — after 10 layers: 0.25¹⁰ ≈ 10⁻⁶. Early layers barely update.
Q23PCATrue / False
Scikit-Learn's PCA automatically centers the data before computing principal components.
AFalse
BTrue
PCA requires zero-mean data. Scikit-Learn subtracts the feature mean before SVD. Without centering, the first PC would point toward the data mean rather than the direction of maximum spread.
Q24PCAMultiple Choice
PCA selects principal components by finding directions that:
AMinimize reconstruction error from a low-dimensional representation
BMaximize the variance of the projected data
CAre orthogonal to the decision boundary of a downstream classifier
DMinimize correlation between input features
PC1 is the direction of maximum variance; PC2 is the direction of most remaining variance orthogonal to PC1; and so on. Maximizing variance is equivalent to minimizing reconstruction error.
Q25GMMMultiple Choice
GMM anomaly detection works by:
AFlagging instances whose assignment changes between E and M steps
BComputing density at each instance and flagging those below a chosen threshold
CFlagging instances assigned to the smallest component by count
DUsing Mahalanobis distance to the nearest component mean
A GMM models data density. Instances in low-density regions are anomalies. You set a threshold on density — instances scoring below it are flagged. The threshold is tuned to the desired false positive rate.
Q26Transfer LearningMultiple Choice
When fine-tuning a pretrained CNN with limited labeled data, you should:
AUnfreeze all layers immediately and train with a large learning rate
BFreeze early layers (which encode general features), train only the new task-specific output layers first, then optionally unfreeze deeper layers with a small learning rate
COnly fine-tune the first convolutional layer
DRandomly reinitialize pretrained weights before fine-tuning
Early CNN layers encode universal features (edges, textures) useful across image tasks. Freezing them preserves these representations. Train only the new head first, then fine-tune deeper layers carefully.
Q27Gradient BoostingMultiple Choice
Gradient Boosting fits each new tree to:
AA random bootstrap sample of the original targets
BThe gradient of the regularization term with respect to tree structure
CThe original targets with higher weights on misclassified instances
DThe residual errors left by the current ensemble
Each new tree fits the pseudo-residuals (y - current_prediction). Adding it reduces the remaining error. This is equivalent to gradient descent in function space.
Q28GMMMultiple Choice
If two GMM components have identical means at initialization, EM will:
AImmediately remove the duplicate component
BAssign both identical responsibilities and update them identically — symmetry is never broken
CRaise a singular matrix error and fail to converge
DBreak symmetry in the M-step by assigning different covariances
Identical initial means → identical E-step responsibilities → identical M-step updates → components stay identical forever. K-Means++ initialization or random perturbation is needed to break this symmetry.
Q29Decision TreesMultiple Choice
Setting min_samples_leaf=20 in a Decision Tree:
AIncreases the learning rate by processing 20 instances per update
BIncreases tree depth by requiring 20 splits per level
CLimits the number of features considered at each split
DRestricts leaves to at least 20 instances, reducing overfitting
min_samples_leaf prevents very specific leaf nodes by requiring a minimum count. This pre-pruning constraint reduces variance at the cost of some bias.
Q30GMMMultiple Choice
In a GMM, the mixing weight φₖ represents:
AThe mean of the k-th Gaussian component
BThe prior probability that a random instance was generated by component k
CThe count of instances assigned to component k
DThe inverse of the covariance of component k
φₖ is the prior probability of being from component k. All mixing weights sum to 1. After observing an instance, the posterior (responsibility) is computed via Bayes' theorem.

Q36Random ForestsMultiple Choice
What distinguishes a Random Forest from a simple bagging ensemble of Decision Trees?
ARandom Forests use boosting; bagging uses averaging
BRandom Forests train trees sequentially; bagging trains in parallel
CAt each split, only a random subset of features is considered, decorrelating individual trees
DRandom Forests use regression trees; bagging uses classification trees
Feature subsampling at each split forces trees to be diverse. Decorrelated trees produce more independent errors, so averaging is more effective at reducing variance.
Q37CNNsMultiple Choice
Global Average Pooling (GAP) before the output layer replaces:
ALarge fully connected layers, dramatically reducing parameters and overfitting risk
BMax pooling layers used for spatial downsampling
CThe early convolutional layers in the network
DBatch normalization layers after each convolution
GAP averages each feature map to a single value, producing a vector of length = number of feature maps. This replaces large dense layers (AlexNet had two FC layers with 4096 units each) with a nearly parameter-free operation.

ABefore each learning rate reduction

COnly when the monitored metric improves — keeping the best-performing version
DAfter every epoch regardless of performance
With save_best_only=True, the model is saved only when val_loss (or monitored metric) improves. This preserves the best weights even if training continues and overfitting begins.
Q39CNNsMultiple Choice
1×1 convolutions in GoogLeNet (Inception) modules are used to:
AReplace max pooling layers for spatial downsampling
BDetect single-pixel features larger filters miss
CApply batch normalization across spatial positions
DReduce the channel count before expensive 3×3 and 5×5 convolutions, cutting computation dramatically
1×1 convolutions perform channel-wise weighted sums — a learned bottleneck. Reducing 192 channels to 32 before a 5×5 conv cuts computation by ~6×. This is the key GoogLeNet efficiency trick.

ADecreased proportional to the predictor error rate

AdaBoost increases weights on misclassified instances. The next predictor then sees an over-represented hard subset, forcing it to focus on correcting current errors.
