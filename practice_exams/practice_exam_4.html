Q1ROC CurveMultiple Choice
The ROC curve for a random classifier looks like:
AA step function jumping at the decision threshold
BA vertical line at FPR=0
CA horizontal line at TPR=1.0
DThe diagonal line from (0,0) to (1,1) with AUC=0.5
A random classifier has TPR=FPR at all thresholds, tracing the diagonal. AUC=0.5. A perfect classifier hugs the top-left corner with AUC=1.0.
Q2Batch vs Online LearningMultiple Choice
Online learning differs from batch learning in that:
AOnline learning is always faster because it processes one instance at a time
BOnline learning cannot handle non-stationary data distributions
COnline learning uses a separate validation set; batch learning does not
DOnline learning updates the model incrementally as new data arrives; batch learning retrains on the full dataset
Online learning updates the model with each new instance or mini-batch, suitable for streaming data. Batch learning accumulates all data and retrains from scratch.
Q3Linear RegressionMultiple Choice
The main computational disadvantage of the Normal Equation when features are numerous is:
AIt only finds a local minimum when features are correlated
BIt requires computing the inverse of XᵀX, scaling as O(n³) in the number of features
CIt cannot handle more than one target variable
DIt requires multiple passes through the training data to converge
Matrix inversion is O(n³) in features n. With thousands of features this is slow. Gradient descent avoids explicit matrix inversion and scales better.
Q4Instance-Based LearningMultiple Choice
k-Nearest Neighbors classifies a new instance using:
AA probabilistic model of the class-conditional distribution
BThe majority class among the k most similar training instances
CA learned decision boundary defined by weight parameters
DThe centroid of the cluster the instance falls into
k-NN is instance-based: it stores all training data and classifies by majority vote among the k nearest neighbors. No explicit model is learned.
Q5KernelsMultiple Choice
The kernel trick allows SVMs to:
AAvoid storing support vectors in memory during prediction
BUse gradient descent instead of quadratic programming
CCompute dot products in a high-dimensional feature space without explicitly computing the transformation
DReduce QP solving time from O(m³) to O(m²)
K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) without materializing φ(x). For infinite-dimensional spaces (RBF kernel), explicit transformation would be impossible — the kernel makes it tractable.
Q6SVMsMultiple Choice
A small value of C in a soft-margin SVM results in:
AA smaller kernel bandwidth making the kernel more local
BA narrow margin with few violations tolerated
CA wide margin with many violations accepted — higher bias, lower variance
DA small learning rate, slowing convergence
Small C penalizes violations lightly → wider margin → more regularization → higher bias, lower variance. Large C penalizes violations heavily → narrower margin → lower bias, higher variance.
Q7RegularizationMultiple Choice
Lasso (L1) can set feature weights to exactly zero while Ridge (L2) cannot. The geometric reason is:
ARidge regularizes the bias term; Lasso does not
BLasso applies a hard threshold; Ridge uses a soft threshold
CRidge uses a squared penalty whose constraint region has corners at axes
DLasso uses an absolute value penalty whose diamond-shaped constraint region has corners at the axes, where zero solutions are likely
The L1 ball is diamond-shaped with corners at the axes. When loss contours touch this region, they most often meet at a corner — where one or more weights equal zero. The L2 ball is smooth with no corners.
Q8Gradient DescentMultiple Choice
Mini-batch gradient descent (batch size 32-256) offers what main advantage over full-batch GD on large datasets?
AIt always converges to a better solution
BIt eliminates the need for a learning rate schedule
CIt provides reasonably accurate gradients efficiently, making better use of GPU hardware
DIt has perfectly accurate gradient estimates using the full dataset
Full batch is slow on large datasets. SGD (batch=1) is noisy. Mini-batches balance accuracy and efficiency, and GPU hardware is optimized for vectorized mini-batch operations.
Q9Performance MeasuresMultiple Choice
Precision = TP / (TP + FP). A precision of 0.80 means:
AThe model misses 20% of actual positives
B80% of actual positives were correctly identified
CWhen the model predicts positive, it is correct 80% of the time
DThe model correctly classifies 80% of all instances
Of all instances predicted positive, 80% were truly positive (TP) and 20% were false alarms (FP). This is precision — not to be confused with recall which measures coverage of actual positives.
Q10Softmax RegressionTrue / False
Softmax regression assumes each instance belongs to exactly one class (mutual exclusivity).
ATrue
BFalse
Softmax outputs sum to 1, enforcing mutual exclusivity. For multi-label problems (multiple classes per instance), use multiple independent binary classifiers with sigmoid outputs instead.
Q11Feature ScalingMultiple Choice
Which algorithm requires no feature scaling preprocessing?
ALogistic Regression with gradient descent
BSupport Vector Machine with RBF kernel
CDecision Tree classifier
Dk-Nearest Neighbors
Decision Trees split on individual feature thresholds — the relative ordering matters, not absolute scale. Logistic regression, k-NN, and SVM depend on distances or dot products and require scaling.
Q12SVMsMultiple Choice
Support vectors are the training instances that:
AAre selected randomly to represent each class during training
BLie on or inside the margin boundaries and uniquely determine the decision hyperplane
CAre correctly classified with the highest confidence
DHave the largest feature values in the dataset
Support vectors are the instances closest to the decision boundary — on or within the margin. Only these matter; removing other instances would not change the hyperplane.
Q13Challenges of MLMultiple Choice
Collecting more training data most directly addresses which ML challenge?
AOverfitting due to insufficient training data
BUnderfitting from an overly simple model
CIrrelevant features reducing signal-to-noise ratio
DNon-representative sampling bias
More data helps the model generalize rather than memorize, directly combating overfitting. It does not fix underfitting, biased sampling, or noisy features.
Q14Softmax RegressionMultiple Choice
Cross-entropy loss for softmax regression is minimized when:
AThe weight matrix has small Frobenius norm
BThe softmax scores are all close to zero
CAll class probabilities are equal
DThe predicted probability for the correct class is near 1
Cross-entropy = -log(p̂ₖ) where k is the true class. Minimized (approaches 0) when p̂ₖ approaches 1. Maximized when the model is confident but wrong.

Q15CNNsMultiple Choice
Max pooling provides local translation invariance because:
AIt retains the strongest activation in each window regardless of exact position within that window
BIt learns optimal downsampling weights via gradient descent
CIt normalizes feature map values to zero mean
DIt applies the same filter regardless of position
If a feature shifts slightly, the max in that pooling window may not change. This robustness to small spatial shifts is local translation invariance.
Q16GMMMultiple Choice
In a GMM, the mixing weight φₖ represents:
AThe mean of the k-th Gaussian component
BThe inverse of the covariance of component k
CThe count of instances assigned to component k
DThe prior probability that a random instance was generated by component k
φₖ is the prior probability of being from component k. All mixing weights sum to 1. After observing an instance, the posterior (responsibility) is computed via Bayes' theorem.
Q17CNNsMultiple Choice
AlexNet's two key innovations enabling its 2012 ImageNet win were:
ADepthwise separable convolutions and skip connections
BBatch normalization and residual connections
CInception modules with parallel filter banks and global average pooling
DReLU activations and dropout regularization, trained on GPUs
AlexNet used ReLU (much faster training, no vanishing gradients) and dropout (prevented overfitting in large FC layers). GPU training allowed a much larger network than prior work.

Q21CNNsMultiple Choice
"Same" padding ensures:
AOutput spatial dimensions equal input dimensions when stride=1
BThe filter size equals the input size
CThe same weights are used for all filter positions
DPadding value matches the input feature map mean

Q22Transfer LearningMultiple Choice
When fine-tuning a pretrained CNN with limited labeled data, you should:
AFreeze early layers (which encode general features), train only the new task-specific output layers first, then optionally unfreeze deeper layers with a small learning rate
BUnfreeze all layers immediately and train with a large learning rate
CRandomly reinitialize pretrained weights before fine-tuning
DOnly fine-tune the first convolutional layer
Early CNN layers encode universal features (edges, textures) useful across image tasks. Freezing them preserves these representations. Train only the new head first, then fine-tune deeper layers carefully.
Q23PCAMultiple Choice
PCA selects principal components by finding directions that:
AMaximize the variance of the projected data
BMinimize reconstruction error from a low-dimensional representation
CAre orthogonal to the decision boundary of a downstream classifier
DMinimize correlation between input features
PC1 is the direction of maximum variance; PC2 is the direction of most remaining variance orthogonal to PC1; and so on. Maximizing variance is equivalent to minimizing reconstruction error.
Q24K-MeansMultiple Choice
The silhouette coefficient near -1 for an instance indicates:
AThe instance is closer to another cluster than its own — possibly misassigned
BThe cluster has much higher inertia than others
CThe instance is very close to its cluster centroid
DThe instance is on the boundary between clusters
s=(b-a)/max(a,b). When b << a (much closer to a neighboring cluster than its own), s approaches -1, suggesting possible misassignment.
Q25GMMMultiple Choice
Compared to K-Means, a GMM is more flexible because:
AIt applies L2 regularization to prevent component collapse
BIt assigns each instance to exactly one cluster deterministically
CEach component has its own covariance matrix, allowing elliptical clusters of different sizes and orientations
DIt does not require specifying the number of components in advance
K-Means assumes spherical equal-size clusters. GMMs have per-component covariances — elliptical clusters with arbitrary orientation and scale. GMMs also perform soft probabilistic assignments.
Q26Neural NetworksMultiple Choice
The Universal Approximation Theorem says a 1-hidden-layer MLP can approximate any continuous function. What it does NOT address:
AWhether sigmoid activations are sufficient for approximation
BWhether ReLU is insufficient for approximation
CWhether gradient descent will find the approximating weights, or how large the network needs to be
DWhether approximation holds for functions with multiple inputs
The theorem proves the existence of approximating weights, but says nothing about whether training will find them, how many neurons are needed in practice, or training time.
Q27Dimensionality ReductionMultiple Choice
The curse of dimensionality means that as feature count grows:
AFeature scaling becomes less important because distances are already large
BTraining data becomes increasingly sparse relative to the space volume, making generalization harder
CRegularization can be reduced because more features prevent overfitting
DModels become more accurate because they have more information
In high dimensions, the same number of training points is spread across exponentially larger volume. Most of the space is far from any training instance, making generalization harder.
Q28Neural NetworksMultiple Choice
ReLU is preferred over sigmoid in hidden layers primarily because:
AFor positive inputs, ReLU derivative = 1, avoiding vanishing gradients, and it is computationally cheap
BReLU outputs are bounded between 0 and 1, stabilizing training
CReLU is differentiable everywhere unlike sigmoid
DReLU automatically normalizes layer outputs
ReLU = max(0,z). Derivative = 1 for z > 0 — no gradient shrinking. Sigmoid derivative ≤ 0.25 — shrinks with depth. ReLU also avoids exponentiation.
Q29PCAMultiple Choice
Using PCA's inverse_transform to reconstruct data produces:
AData with more dimensions than the original
BA lossy approximation — discarded components represent lost information
CReconstruction valid only for training instances
DExact reconstruction — PCA is lossless
PCA discards low-variance components so reconstruction is approximate. The reconstruction error is the mean squared distance between original and reconstructed instances.
Q30K-MeansMultiple Choice
K-Means struggles with clusters of very different densities because:
AIt only finds exactly k clusters so unequal sizes cause convergence failure
BIt cannot handle continuous features
CIt requires spherical clusters and uses Manhattan distance
DIt minimizes total squared distance without penalizing imbalanced sizes — dense small clusters can be absorbed by large nearby ones
K-Means has no mechanism protecting small dense clusters. A large cluster's centroid can attract nearby dense cluster instances if that reduces total inertia.

BTanh with hinge loss

DSigmoid with binary cross-entropy

Q33Neural NetworksMultiple Choice
The vanishing gradient problem in deep sigmoid/tanh networks occurs because:
ASigmoid/tanh derivatives are small (< 1), so gradients shrink exponentially as they propagate backward through many layers
BBatch normalization clips gradients during backpropagation
CThe loss function is non-convex, trapping gradients in local minima
DWeights grow too large, causing numerical overflow
During backpropagation, gradients multiply by activation derivatives at each layer. Sigmoid/tanh derivatives ≤ 0.25 — after 10 layers: 0.25¹⁰ ≈ 10⁻⁶. Early layers barely update.
Q34CNNsMultiple Choice
The number of parameters in a conv layer with 64 filters, 3×3 kernel, 32 input channels is:
A3 × 3 × 32 × 64 = 18,432
B(3 × 3 × 32 + 1) × 64 = 18,496
C64 × 32 = 2,048
D64 × 3 × 3 = 576
Each filter: 3×3×32=288 weights + 1 bias = 289. With 64 filters: 289×64 = 18,496 total. The +1 per filter accounts for the bias term (one bias per output feature map).

Q39Ensemble MethodsMultiple Choice
In stacking, the blender (meta-learner) is trained on:
AThe original training features using all base predictors simultaneously
BA random subset of base predictor outputs selected by cross-validation
CTest set predictions after all base predictors are fully trained
DOut-of-fold predictions from the base predictors — not the raw inputs
The blender trains on what base predictors output for data they did not train on (out-of-fold). This prevents the blender from overfitting to memorized training outputs.
Q40CNNsMultiple Choice
Global Average Pooling (GAP) before the output layer replaces:
ABatch normalization layers after each convolution
BThe early convolutional layers in the network
CMax pooling layers used for spatial downsampling
DLarge fully connected layers, dramatically reducing parameters and overfitting risk
GAP averages each feature map to a single value, producing a vector of length = number of feature maps. This replaces large dense layers (AlexNet had two FC layers with 4096 units each) with a nearly parameter-free operation.
