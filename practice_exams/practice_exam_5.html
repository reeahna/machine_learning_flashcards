Q1Evaluation MetricsMultiple Choice
The F1 score uses the harmonic mean because:
AIt is faster to compute than the arithmetic mean
BIt is always larger than the arithmetic mean, giving a more optimistic estimate
CIt is dominated by whichever of precision/recall is smaller, requiring both to be high for a high F1
DIt penalizes classifiers with similar precision and recall
Harmonic mean of P and R = 2PR/(P+R). If either is near zero, F1 is near zero. You cannot compensate for poor recall with high precision or vice versa.
Q2ClassificationMultiple Choice
When should you prefer precision-recall curves over ROC curves?
AWhen the positive class is rare — ROC can look misleadingly good when the negative class is dominant
BWhen comparing models from different algorithm families
CWhen training set size is small
DWhen the model is multi-class and one class dominates
With severe class imbalance, many TN makes FPR very low even for bad models, inflating ROC AUC. The PR curve focuses on the minority positive class and is more informative here.
Q3Confusion MatrixMultiple Choice
A false positive in binary classification is:
AA positive instance correctly classified as positive
BA positive instance incorrectly classified as negative
CA negative instance correctly classified as negative
DA negative instance incorrectly classified as positive
False positive: true label is negative but model predicted positive. Contributes to reduced precision. False negative: true positive predicted as negative, reducing recall.
Q4Challenges of MLMultiple Choice
Collecting more training data most directly addresses which ML challenge?
ANon-representative sampling bias
BOverfitting due to insufficient training data
CIrrelevant features reducing signal-to-noise ratio
DUnderfitting from an overly simple model
More data helps the model generalize rather than memorize, directly combating overfitting. It does not fix underfitting, biased sampling, or noisy features.
Q5SVMsMultiple Choice
A small value of C in a soft-margin SVM results in:
AA narrow margin with few violations tolerated
BA small learning rate, slowing convergence
CA wide margin with many violations accepted — higher bias, lower variance
DA smaller kernel bandwidth making the kernel more local
Small C penalizes violations lightly → wider margin → more regularization → higher bias, lower variance. Large C penalizes violations heavily → narrower margin → lower bias, higher variance.

Q7Softmax RegressionTrue / False
Softmax regression assumes each instance belongs to exactly one class (mutual exclusivity).
AFalse
BTrue

Q8Gradient DescentMultiple Choice
A learning rate that is too large in gradient descent causes:
AGradient estimates biased toward the majority class
BVery slow convergence requiring many iterations
CUnderfitting because large updates skip the optimal parameters
DThe algorithm to overshoot the minimum and potentially diverge

Q9SVMsMultiple Choice
Maximizing the margin in SVMs (minimizing ||w||) produces models that:
ASet ||w|| = 1 as a normalization constraint
BAre less sensitive to small perturbations in training data, reducing variance
CCompute ||w|| as a function of support vector coordinates
DMaximize ||w|| — giving more weight to important features
A large margin means the boundary is far from all training instances. The classifier is robust to small perturbations — a new instance needs to be far from training data to be misclassified.
Q10Softmax RegressionMultiple Choice
Softmax regression extends logistic regression to K classes by:
ATraining K independent logistic regressors and selecting the highest output
BApplying a sigmoid to each of K binary feature encodings
CUsing OvO binary classification internally for each class pair
DComputing one score per class and converting all scores to a probability distribution via the softmax function
Softmax computes sₖ = θₖᵀx for each class, then applies softmax to produce probabilities summing to 1. Trained end-to-end with cross-entropy loss.
Q11RegularizationMultiple Choice
Lasso (L1) can set feature weights to exactly zero while Ridge (L2) cannot. The geometric reason is:
ARidge uses a squared penalty whose constraint region has corners at axes
BLasso uses an absolute value penalty whose diamond-shaped constraint region has corners at the axes, where zero solutions are likely
CLasso applies a hard threshold; Ridge uses a soft threshold
DRidge regularizes the bias term; Lasso does not
The L1 ball is diamond-shaped with corners at the axes. When loss contours touch this region, they most often meet at a corner — where one or more weights equal zero. The L2 ball is smooth with no corners.
Q12SVMsMultiple Choice
SVM regression (SVR) tries to:
AUse the hinge loss for each misclassified instance
BFit instances within an epsilon-wide tube, penalizing those outside
CMaximize the margin between two regression target ranges
DRequire the target variable to be binary
SVR finds a tube of width 2ε around predictions. Instances inside contribute zero loss. Only those outside (violations) are penalized. Inverse of classification which maximizes the margin between classes.
Q13Gradient DescentMultiple Choice
Stochastic gradient descent (batch size = 1) can escape shallow local minima because:
AIt uses a smaller learning rate, making finer adjustments near minima
BIts noisy single-instance gradient estimates can push parameters out of shallow minima that batch GD would get stuck in
CIt randomizes the activation function at each step
DIt computes a more accurate gradient by using all instances
SGD gradient noise is useful — it can bounce parameters out of shallow local minima. Smooth batch GD follows the gradient exactly and may get stuck.
Q14ROC CurveMultiple Choice
The ROC curve for a random classifier looks like:
AThe diagonal line from (0,0) to (1,1) with AUC=0.5
BA horizontal line at TPR=1.0
CA vertical line at FPR=0
DA step function jumping at the decision threshold
A random classifier has TPR=FPR at all thresholds, tracing the diagonal. AUC=0.5. A perfect classifier hugs the top-left corner with AUC=1.0.
Section B — Post-Midterm Material (Lectures 10–19)
Q15Dimensionality ReductionTrue / False
Dimensionality reduction always improves downstream classifier accuracy by removing noise.
AFalse
BTrue
PCA discards low-variance components which might contain useful signal. It can speed up training and reduce overfitting, but it is not guaranteed to improve accuracy. Always validate on a held-out set.
Q16CNNsMultiple Choice
1×1 convolutions in GoogLeNet (Inception) modules are used to:
ADetect single-pixel features larger filters miss
BReplace max pooling layers for spatial downsampling
CReduce the channel count before expensive 3×3 and 5×5 convolutions, cutting computation dramatically
DApply batch normalization across spatial positions
1×1 convolutions perform channel-wise weighted sums — a learned bottleneck. Reducing 192 channels to 32 before a 5×5 conv cuts computation by ~6×. This is the key GoogLeNet efficiency trick.
Q17Random ForestsMultiple Choice
What distinguishes a Random Forest from a simple bagging ensemble of Decision Trees?
ARandom Forests use boosting; bagging uses averaging
BRandom Forests use regression trees; bagging uses classification trees
CRandom Forests train trees sequentially; bagging trains in parallel
DAt each split, only a random subset of features is considered, decorrelating individual trees
Feature subsampling at each split forces trees to be diverse. Decorrelated trees produce more independent errors, so averaging is more effective at reducing variance.
Q18Ensemble MethodsMultiple Choice
In AdaBoost, misclassified instances after each round have their weights:
ADecreased proportional to the predictor error rate
BSet to zero so those instances are ignored next round
CLeft unchanged — only the predictor weight changes
DIncreased so the next predictor focuses more on hard instances
AdaBoost increases weights on misclassified instances. The next predictor then sees an over-represented hard subset, forcing it to focus on correcting current errors.
Q19Decision TreesMultiple Choice

AThe variance of the split feature

CThe total depth of the resulting subtree
DThe number of instances in the smaller child
CART minimizes (m_left/m)·G_left + (m_right/m)·G_right, searching all features and thresholds greedily at each node.

Q24Decision TreesTrue / False
Decision Trees are sensitive to small changes in training data — removing a few instances can significantly alter the learned tree.
ATrue
BFalse
Decision Trees have high variance. A slight change in training data can produce a completely different tree. This instability motivates Random Forests, which average many trees.

Q29Dimensionality ReductionMultiple Choice
The curse of dimensionality means that as feature count grows:
AFeature scaling becomes less important because distances are already large
BTraining data becomes increasingly sparse relative to the space volume, making generalization harder
CRegularization can be reduced because more features prevent overfitting
DModels become more accurate because they have more information
In high dimensions, the same number of training points is spread across exponentially larger volume. Most of the space is far from any training instance, making generalization harder.

Q33Transfer LearningMultiple Choice

Q37CNNsMultiple Choice

Q38GMMMultiple Choice
EM for GMMs is guaranteed to converge, but to:
AExactly k clusters with equal covariance matrices
BThe minimum AIC solution among all Gaussian mixtures
CA local maximum — the result depends on initialization
DThe global maximum of the log-likelihood

Q39PCAMultiple Choice
PCA selects principal components by finding directions that:
AMinimize reconstruction error from a low-dimensional representation
BAre orthogonal to the decision boundary of a downstream classifier
CMaximize the variance of the projected data
DMinimize correlation between input features
PC1 is the direction of maximum variance; PC2 is the direction of most remaining variance orthogonal to PC1; and so on. Maximizing variance is equivalent to minimizing reconstruction error.
Q40GMMMultiple Choice
GMM anomaly detection works by:
AFlagging instances whose assignment changes between E and M steps
BFlagging instances assigned to the smallest component by count
CUsing Mahalanobis distance to the nearest component mean
DComputing density at each instance and flagging those below a chosen threshold
A GMM models data density. Instances in low-density regions are anomalies. You set a threshold on density — instances scoring below it are flagged. The threshold is tuned to the desired false positive rate.
