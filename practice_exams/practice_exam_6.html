Q2Logistic RegressionMultiple Choice
Why is there no closed-form solution for logistic regression?
AThe sigmoid is not differentiable, preventing exact gradient computation
BThe log loss contains sigmoid functions that make the gradient transcendental — not solvable algebraically
CThe decision boundary must be computed iteratively
DThe log loss is non-convex, preventing analytical minimization
Unlike MSE for linear regression, the logistic log loss gradient cannot be set to zero and solved in closed form. The sigmoid makes it transcendental. Iterative optimization (gradient descent) is required.
Q3Learning CurvesMultiple Choice
A learning curve showing high training error and similar high validation error indicates:
AOverfitting — the model is too complex
BUnderfitting — the model lacks capacity to capture the data patterns
CGood generalization — train and validation errors are close
DHigh variance — adding more data will not help
When both errors are high and similar, the model underfits. Adding more data will not help. The fix is to increase model capacity.
Q4Logistic RegressionMultiple Choice
When would you add polynomial features to logistic regression?
AWhen the dataset has more features than instances
BWhen classes are linearly separable — polynomial features improve the margin
CWhen the true decision boundary is nonlinear — polynomial features allow curved boundaries
DWhen L2 regularization linearizes the boundary
Logistic regression has a linear boundary in input features. For nonlinear boundaries you manually add polynomial features (x₁², x₁x₂, etc.) to let the model fit more complex shapes.
Q5Performance MeasuresMultiple Choice
Precision = TP / (TP + FP). A precision of 0.80 means:
AWhen the model predicts positive, it is correct 80% of the time
BThe model correctly classifies 80% of all instances
C80% of actual positives were correctly identified
DThe model misses 20% of actual positives
Of all instances predicted positive, 80% were truly positive (TP) and 20% were false alarms (FP). This is precision — not to be confused with recall which measures coverage of actual positives.
Q6ROC CurveMultiple Choice
The ROC curve for a random classifier looks like:
AA step function jumping at the decision threshold
BA vertical line at FPR=0
CThe diagonal line from (0,0) to (1,1) with AUC=0.5
DA horizontal line at TPR=1.0
A random classifier has TPR=FPR at all thresholds, tracing the diagonal. AUC=0.5. A perfect classifier hugs the top-left corner with AUC=1.0.
Q7Cross-ValidationMultiple Choice
In 10-fold cross-validation, each fold uses what percentage of the data for validation?
A50%
B90%
C1%
D10%
With 10 folds, 1/10 = 10% is held out for validation in each fold; 90% is used for training. This repeats 10 times with different validation folds.
Q8Gradient DescentMultiple Choice
Mini-batch gradient descent (batch size 32-256) offers what main advantage over full-batch GD on large datasets?
AIt has perfectly accurate gradient estimates using the full dataset
BIt eliminates the need for a learning rate schedule
CIt provides reasonably accurate gradients efficiently, making better use of GPU hardware
DIt always converges to a better solution
Full batch is slow on large datasets. SGD (batch=1) is noisy. Mini-batches balance accuracy and efficiency, and GPU hardware is optimized for vectorized mini-batch operations.
Q9SVMsMultiple Choice
Maximizing the margin in SVMs (minimizing ||w||) produces models that:
AAre less sensitive to small perturbations in training data, reducing variance
BMaximize ||w|| — giving more weight to important features
CSet ||w|| = 1 as a normalization constraint
DCompute ||w|| as a function of support vector coordinates
A large margin means the boundary is far from all training instances. The classifier is robust to small perturbations — a new instance needs to be far from training data to be misclassified.
Q10Data PreparationMultiple Choice

ANaive Bayes
BRandom Forests
CSVM with RBF kernel
DDecision Trees

Q11Instance-Based LearningMultiple Choice
k-Nearest Neighbors classifies a new instance using:
AThe majority class among the k most similar training instances
BA learned decision boundary defined by weight parameters
CThe centroid of the cluster the instance falls into
DA probabilistic model of the class-conditional distribution
k-NN is instance-based: it stores all training data and classifies by majority vote among the k nearest neighbors. No explicit model is learned.
Q12Challenges of MLMultiple Choice
Collecting more training data most directly addresses which ML challenge?
AUnderfitting from an overly simple model
BOverfitting due to insufficient training data
CNon-representative sampling bias
DIrrelevant features reducing signal-to-noise ratio
More data helps the model generalize rather than memorize, directly combating overfitting. It does not fix underfitting, biased sampling, or noisy features.
Q13Multi-Class ClassificationMultiple Choice
OvO (One vs. One) strategy trains how many classifiers for K classes?
AK-1
BK²
CK(K-1)/2
DK
OvO trains one classifier per pair. For K classes: K(K-1)/2 classifiers. For 10 classes: 45 classifiers. OvR trains K classifiers.
Q14Softmax RegressionTrue / False
Softmax regression assumes each instance belongs to exactly one class (mutual exclusivity).
ATrue
BFalse
Softmax outputs sum to 1, enforcing mutual exclusivity. For multi-label problems (multiple classes per instance), use multiple independent binary classifiers with sigmoid outputs instead.

Q15Neural NetworksMultiple Choice
For multi-class classification, the standard output layer is:
ASigmoid with binary cross-entropy
BTanh with hinge loss
CSoftmax with categorical cross-entropy
DReLU with MSE loss
Softmax produces a probability distribution over K classes summing to 1. Categorical cross-entropy measures divergence from the one-hot true label. This combination is standard for multi-class classification.
Q16Neural NetworksMultiple Choice
The Universal Approximation Theorem says a 1-hidden-layer MLP can approximate any continuous function. What it does NOT address:
AWhether approximation holds for functions with multiple inputs
BWhether ReLU is insufficient for approximation
CWhether gradient descent will find the approximating weights, or how large the network needs to be
DWhether sigmoid activations are sufficient for approximation
The theorem proves the existence of approximating weights, but says nothing about whether training will find them, how many neurons are needed in practice, or training time.
Q17GMMMultiple Choice
BIC penalizes model complexity more than AIC. For large datasets, this means BIC tends to select:
AFewer components (simpler models) than AIC
BMore components than AIC
CComponents with higher log-likelihood regardless of count
DThe same number of components as AIC
BIC uses log(m) as penalty coefficient; AIC uses 2. For large m, log(m) > 2 so BIC penalizes each extra parameter more heavily, pushing toward simpler models.
Q18K-MeansMultiple Choice

AInertia reaches exactly zero

DCentroids have been updated a fixed number of times

Q19Neural NetworksMulti-Select
Which statements about ReLU are correct? (Select all that apply)
Select all that apply, then click Submit.
AReLU can produce dead neurons that always output zero
BReLU is the default activation for hidden layers in modern DNNs
CReLU outputs are zero-centered
DReLU has no vanishing gradient for positive inputs
ReLU derivative=1 for z>0 (no vanishing gradient) and can produce dead neurons (z≤0, gradient=0). It is the standard hidden layer activation. Outputs are NOT zero-centered (range: 0 to ∞).
Q20PCAMultiple Choice
Using PCA's inverse_transform to reconstruct data produces:
AA lossy approximation — discarded components represent lost information
BData with more dimensions than the original
CExact reconstruction — PCA is lossless
DReconstruction valid only for training instances
PCA discards low-variance components so reconstruction is approximate. The reconstruction error is the mean squared distance between original and reconstructed instances.
Q21Decision TreesMultiple Choice
A Decision Tree leaf predicts class probabilities by:
AApplying softmax to scores stored in the leaf
BReturning the proportion of each class among training instances in that leaf
CAveraging Gini scores from all ancestor nodes
DRunning logistic regression on instances in the leaf
The leaf stores the class distribution from training. The fraction of each class is the estimated probability. The predicted class is the majority class.
Q22CNNsMultiple Choice

Q25GMMMultiple Choice
If two GMM components have identical means at initialization, EM will:
ABreak symmetry in the M-step by assigning different covariances
BImmediately remove the duplicate component
CAssign both identical responsibilities and update them identically — symmetry is never broken
DRaise a singular matrix error and fail to converge
Identical initial means → identical E-step responsibilities → identical M-step updates → components stay identical forever. K-Means++ initialization or random perturbation is needed to break this symmetry.
Q26Decision TreesMultiple Choice
Why is finding the globally optimal Decision Tree NP-hard?
AGini impurity is not differentiable so gradient descent fails
BThe optimal depth depends on the test set
CThe number of possible trees grows exponentially — exact search is infeasible
DDecision boundaries must stay axis-aligned, limiting search space

Q27GMMMultiple Choice
In a GMM, the mixing weight φₖ represents:
AThe count of instances assigned to component k
BThe mean of the k-th Gaussian component
CThe prior probability that a random instance was generated by component k
DThe inverse of the covariance of component k
φₖ is the prior probability of being from component k. All mixing weights sum to 1. After observing an instance, the posterior (responsibility) is computed via Bayes' theorem.
Q28Decision TreesTrue / False
Decision Trees are sensitive to small changes in training data — removing a few instances can significantly alter the learned tree.
AFalse
BTrue
Decision Trees have high variance. A slight change in training data can produce a completely different tree. This instability motivates Random Forests, which average many trees.
Q29K-MeansTrue / False
K-Means always produces the same clustering result when run multiple times on the same data.
ATrue
BFalse
K-Means is sensitive to initialization. Different seeds can produce different local minima. Scikit-Learn runs n_init=10 times by default and keeps the result with lowest inertia.
Q30Random ForestsTrue / False
Random Forests are more prone to overfitting than a single deep Decision Tree because they combine many complex models.
AFalse
BTrue
False. Averaging many diverse trees reduces variance without much bias increase. Random Forests are generally more robust to overfitting than a single deep decision tree.
Q31Transfer LearningMultiple Choice
When fine-tuning a pretrained CNN with limited labeled data, you should:
AUnfreeze all layers immediately and train with a large learning rate
BOnly fine-tune the first convolutional layer
CFreeze early layers (which encode general features), train only the new task-specific output layers first, then optionally unfreeze deeper layers with a small learning rate
DRandomly reinitialize pretrained weights before fine-tuning
Early CNN layers encode universal features (edges, textures) useful across image tasks. Freezing them preserves these representations. Train only the new head first, then fine-tune deeper layers carefully.
Q32Ensemble MethodsMultiple Choice

Q34CNNsMultiple Choice
"Same" padding ensures:
APadding value matches the input feature map mean
BThe filter size equals the input size
COutput spatial dimensions equal input dimensions when stride=1
DThe same weights are used for all filter positions
"Same" padding adds zeros so output height and width match input (for stride=1). "Valid" padding adds no padding, shrinking output by filter_size - 1 in each dimension.
Q35GMMMultiple Choice
EM for GMMs is guaranteed to converge, but to:
AA local maximum — the result depends on initialization
BThe minimum AIC solution among all Gaussian mixtures
CThe global maximum of the log-likelihood
DExactly k clusters with equal covariance matrices
EM strictly increases log-likelihood each iteration (guaranteed convergence). But the GMM log-likelihood surface has many local maxima — EM finds one near the initialization.
Q36K-MeansMultiple Choice
The silhouette coefficient near -1 for an instance indicates:
AThe cluster has much higher inertia than others
BThe instance is very close to its cluster centroid
CThe instance is on the boundary between clusters
DThe instance is closer to another cluster than its own — possibly misassigned
s=(b-a)/max(a,b). When b << a (much closer to a neighboring cluster than its own), s approaches -1, suggesting possible misassignment.
Q37CNNsMultiple Choice
1×1 convolutions in GoogLeNet (Inception) modules are used to:
AApply batch normalization across spatial positions
BDetect single-pixel features larger filters miss
CReduce the channel count before expensive 3×3 and 5×5 convolutions, cutting computation dramatically
DReplace max pooling layers for spatial downsampling
1×1 convolutions perform channel-wise weighted sums — a learned bottleneck. Reducing 192 channels to 32 before a 5×5 conv cuts computation by ~6×. This is the key GoogLeNet efficiency trick.
Q38KerasMultiple Choice
model.compile() configures:
ABatch size, epochs, and validation split
BWeight initialization scheme and random seed
CThe number of layers and units per layer
DThe optimizer, loss function, and evaluation metrics for training
compile() sets the optimizer (update rule), loss (what to minimize), and metrics (tracked but not optimized). Architecture is defined before compile(); batch size and epochs go in fit().
Q39KerasMultiple Choice
The Functional API in Keras is needed when:
AThe model uses dropout or batch normalization
BThe model needs to be serialized to disk
CThe model has multiple inputs, multiple outputs, or shared layers
DThe model has more than 5 layers

Q40Neural NetworksMultiple Choice
For a regression problem with a single continuous target, the output layer should use:
AReLU to ensure non-negative predictions in all cases
BSoftmax activation with one neuron per possible value
CLinear (no) activation with one output neuron, trained with MSE
