Q1Confusion MatrixMultiple Choice
A false positive in binary classification is:
AA positive instance correctly classified as positive
BA positive instance incorrectly classified as negative
CA negative instance correctly classified as negative
DA negative instance incorrectly classified as positive
False positive: true label is negative but model predicted positive. Contributes to reduced precision. False negative: true positive predicted as negative, reducing recall.
Q2KernelsMultiple Choice
The kernel trick allows SVMs to:
AReduce QP solving time from O(m³) to O(m²)
BUse gradient descent instead of quadratic programming
CCompute dot products in a high-dimensional feature space without explicitly computing the transformation
DAvoid storing support vectors in memory during prediction
K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) without materializing φ(x). For infinite-dimensional spaces (RBF kernel), explicit transformation would be impossible — the kernel makes it tractable.

Q6Logistic RegressionMultiple Choice
Why is there no closed-form solution for logistic regression?
AThe decision boundary must be computed iteratively
BThe sigmoid is not differentiable, preventing exact gradient computation
CThe log loss is non-convex, preventing analytical minimization
DThe log loss contains sigmoid functions that make the gradient transcendental — not solvable algebraically
Unlike MSE for linear regression, the logistic log loss gradient cannot be set to zero and solved in closed form. The sigmoid makes it transcendental. Iterative optimization (gradient descent) is required.
Q7SVMsMultiple Choice

AMaximize ||w|| — giving more weight to important features
BSet ||w|| = 1 as a normalization constraint
CAre less sensitive to small perturbations in training data, reducing variance
DCompute ||w|| as a function of support vector coordinates
A large margin means the boundary is far from all training instances. The classifier is robust to small perturbations — a new instance needs to be far from training data to be misclassified.
Q8Performance MeasuresMultiple Choice
Precision = TP / (TP + FP). A precision of 0.80 means:
AWhen the model predicts positive, it is correct 80% of the time
BThe model correctly classifies 80% of all instances
C80% of actual positives were correctly identified
DThe model misses 20% of actual positives
Of all instances predicted positive, 80% were truly positive (TP) and 20% were false alarms (FP). This is precision — not to be confused with recall which measures coverage of actual positives.

Q10Evaluation MetricsMultiple Choice
High precision and low recall on the positive class means:
AThe model is indiscriminate — predicts positive for almost every instance
BBoth precision and recall are dominated by the negative class
CThe model predicts negative for almost every instance
DWhen the model predicts positive it is usually right, but it misses many actual positives
Precision = TP/(TP+FP): when it predicts positive, it is correct. Recall = TP/(TP+FN): but it misses many actual positives. Example: a conservative cancer detector that rarely fires but is reliable when it does.

Q12Performance MeasuresMultiple Choice
RMSE penalizes large prediction errors more heavily than MAE because:
ARMSE normalizes by the number of instances; MAE does not
BRMSE is bounded between 0 and 1; MAE is not
CRMSE uses absolute values; MAE uses squared values
DRMSE squares each error before averaging, so large errors contribute disproportionately
RMSE = sqrt(mean(errors²)). Squaring amplifies large errors. MAE = mean(|errors|) treats all errors proportionally. RMSE is preferred when large errors are especially costly.
Q13Softmax RegressionMultiple Choice
Softmax regression extends logistic regression to K classes by:
AApplying a sigmoid to each of K binary feature encodings
BUsing OvO binary classification internally for each class pair
CComputing one score per class and converting all scores to a probability distribution via the softmax function
DTraining K independent logistic regressors and selecting the highest output
Softmax computes sₖ = θₖᵀx for each class, then applies softmax to produce probabilities summing to 1. Trained end-to-end with cross-entropy loss.

Q18Dimensionality ReductionMultiple Choice
The curse of dimensionality means that as feature count grows:
ARegularization can be reduced because more features prevent overfitting
BFeature scaling becomes less important because distances are already large
CModels become more accurate because they have more information
DTraining data becomes increasingly sparse relative to the space volume, making generalization harder

Q22PCAMultiple Choice
PCA selects principal components by finding directions that:
AMinimize reconstruction error from a low-dimensional representation
BMaximize the variance of the projected data
CMinimize correlation between input features
DAre orthogonal to the decision boundary of a downstream classifier
PC1 is the direction of maximum variance; PC2 is the direction of most remaining variance orthogonal to PC1; and so on. Maximizing variance is equivalent to minimizing reconstruction error.

BReLU has no vanishing gradient for positive inputs
