Q1Softmax RegressionMultiple Choice
Cross-entropy loss for softmax regression is minimized when:
AThe weight matrix has small Frobenius norm
BAll class probabilities are equal
CThe predicted probability for the correct class is near 1
DThe softmax scores are all close to zero
Cross-entropy = -log(p̂ₖ) where k is the true class. Minimized (approaches 0) when p̂ₖ approaches 1. Maximized when the model is confident but wrong.
Q2KernelsMultiple Choice
The kernel trick allows SVMs to:
AReduce QP solving time from O(m³) to O(m²)
BAvoid storing support vectors in memory during prediction
CUse gradient descent instead of quadratic programming
DCompute dot products in a high-dimensional feature space without explicitly computing the transformation
K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) without materializing φ(x). For infinite-dimensional spaces (RBF kernel), explicit transformation would be impossible — the kernel makes it tractable.
Q3Performance MeasuresMultiple Choice
Precision = TP / (TP + FP). A precision of 0.80 means:
A80% of actual positives were correctly identified
BThe model correctly classifies 80% of all instances
CWhen the model predicts positive, it is correct 80% of the time
DThe model misses 20% of actual positives
Of all instances predicted positive, 80% were truly positive (TP) and 20% were false alarms (FP). This is precision — not to be confused with recall which measures coverage of actual positives.

BReinforcement learning
CSelf-supervised learning
DSupervised learning

Q5SVMsMultiple Choice
A small value of C in a soft-margin SVM results in:
AA wide margin with many violations accepted — higher bias, lower variance
BA narrow margin with few violations tolerated
CA small learning rate, slowing convergence
DA smaller kernel bandwidth making the kernel more local
Small C penalizes violations lightly → wider margin → more regularization → higher bias, lower variance. Large C penalizes violations heavily → narrower margin → lower bias, higher variance.
Q6Softmax RegressionMultiple Choice
Softmax regression extends logistic regression to K classes by:
AUsing OvO binary classification internally for each class pair
BComputing one score per class and converting all scores to a probability distribution via the softmax function
CTraining K independent logistic regressors and selecting the highest output
DApplying a sigmoid to each of K binary feature encodings
Softmax computes sₖ = θₖᵀx for each class, then applies softmax to produce probabilities summing to 1. Trained end-to-end with cross-entropy loss.

Q13Logistic RegressionMultiple Choice
Why is there no closed-form solution for logistic regression?
AThe log loss contains sigmoid functions that make the gradient transcendental — not solvable algebraically
BThe decision boundary must be computed iteratively
CThe sigmoid is not differentiable, preventing exact gradient computation
DThe log loss is non-convex, preventing analytical minimization
Unlike MSE for linear regression, the logistic log loss gradient cannot be set to zero and solved in closed form. The sigmoid makes it transcendental. Iterative optimization (gradient descent) is required.
Q14Cross-ValidationMultiple Choice
In 10-fold cross-validation, each fold uses what percentage of the data for validation?
A10%
B50%
C90%
D1%
With 10 folds, 1/10 = 10% is held out for validation in each fold; 90% is used for training. This repeats 10 times with different validation folds.

Q15Dimensionality ReductionMultiple Choice

BHigh-dimensional real-world data typically lies near a lower-dimensional nonlinear manifold
CDimensionality reduction always improves downstream model accuracy

Q16PCAMultiple Choice
PCA selects principal components by finding directions that:
AAre orthogonal to the decision boundary of a downstream classifier
BMinimize correlation between input features
CMaximize the variance of the projected data
DMinimize reconstruction error from a low-dimensional representation
PC1 is the direction of maximum variance; PC2 is the direction of most remaining variance orthogonal to PC1; and so on. Maximizing variance is equivalent to minimizing reconstruction error.
Q17CNNsMultiple Choice
1×1 convolutions in GoogLeNet (Inception) modules are used to:
ADetect single-pixel features larger filters miss
BApply batch normalization across spatial positions
CReplace max pooling layers for spatial downsampling
DReduce the channel count before expensive 3×3 and 5×5 convolutions, cutting computation dramatically
1×1 convolutions perform channel-wise weighted sums — a learned bottleneck. Reducing 192 channels to 32 before a 5×5 conv cuts computation by ~6×. This is the key GoogLeNet efficiency trick.
Q18Dimensionality ReductionMultiple Choice
The curse of dimensionality means that as feature count grows:
AModels become more accurate because they have more information
BTraining data becomes increasingly sparse relative to the space volume, making generalization harder
CFeature scaling becomes less important because distances are already large
DRegularization can be reduced because more features prevent overfitting
In high dimensions, the same number of training points is spread across exponentially larger volume. Most of the space is far from any training instance, making generalization harder.
Q19PCAMultiple Choice
Using PCA's inverse_transform to reconstruct data produces:
AA lossy approximation — discarded components represent lost information
BData with more dimensions than the original
CExact reconstruction — PCA is lossless
DReconstruction valid only for training instances
PCA discards low-variance components so reconstruction is approximate. The reconstruction error is the mean squared distance between original and reconstructed instances.
Q20K-MeansMultiple Choice
K-Means++ initialization places each new centroid:
AWith probability proportional to its squared distance from the nearest existing centroid
BAt equal intervals along the first principal component
CAt the instance with highest variance
DAt the mean of each feature's distribution
K-Means++ spreads centroids out. Each new centroid is more likely to land far from existing ones, reducing poor initialization and typically giving better final clusters.
Q21CNNsMultiple Choice
AlexNet's two key innovations enabling its 2012 ImageNet win were:
AInception modules with parallel filter banks and global average pooling
BBatch normalization and residual connections
CReLU activations and dropout regularization, trained on GPUs
DDepthwise separable convolutions and skip connections
AlexNet used ReLU (much faster training, no vanishing gradients) and dropout (prevented overfitting in large FC layers). GPU training allowed a much larger network than prior work.
Q22GMMMultiple Choice
If two GMM components have identical means at initialization, EM will:
AAssign both identical responsibilities and update them identically — symmetry is never broken
BRaise a singular matrix error and fail to converge
CImmediately remove the duplicate component
DBreak symmetry in the M-step by assigning different covariances
Identical initial means → identical E-step responsibilities → identical M-step updates → components stay identical forever. K-Means++ initialization or random perturbation is needed to break this symmetry.
Q23Neural NetworksMultiple Choice
The vanishing gradient problem in deep sigmoid/tanh networks occurs because:
ASigmoid/tanh derivatives are small (< 1), so gradients shrink exponentially as they propagate backward through many layers
BWeights grow too large, causing numerical overflow
CBatch normalization clips gradients during backpropagation
DThe loss function is non-convex, trapping gradients in local minima
During backpropagation, gradients multiply by activation derivatives at each layer. Sigmoid/tanh derivatives ≤ 0.25 — after 10 layers: 0.25¹⁰ ≈ 10⁻⁶. Early layers barely update.
Q24Neural NetworksMultiple Choice
For multi-class classification, the standard output layer is:
AReLU with MSE loss
BTanh with hinge loss
CSigmoid with binary cross-entropy
DSoftmax with categorical cross-entropy
Softmax produces a probability distribution over K classes summing to 1. Categorical cross-entropy measures divergence from the one-hot true label. This combination is standard for multi-class classification.
Q25Neural NetworksMultiple Choice
Tanh is preferred over sigmoid in hidden layers because:
ATanh is faster to compute, avoiding exponentiation
BTanh produces sparser activations, reducing overfitting
CTanh outputs are zero-centered, avoiding zig-zagging gradient updates
DTanh eliminates vanishing gradients — its derivative is 1 everywhere
Zero-centered outputs (range -1 to 1) mean downstream gradients can be positive or negative. Sigmoid outputs (all positive) cause all gradients to have the same sign, producing zig-zagging in weight space.

Q27Neural NetworksMultiple Choice
Zero weight initialization causes training to fail because:
AZero weights force all activations to 0.5
BAll neurons in each layer produce identical outputs and gradients, remaining identical forever — the symmetry problem
CZero initialization prevents the loss from decreasing below a minimum
DZero weights cause numerical overflow in the first backward pass
Identical weights → identical activations → identical gradients → identical updates → weights stay identical. The network effectively has one neuron per layer. Random initialization breaks this symmetry.

Q32Transfer LearningMultiple Choice
When fine-tuning a pretrained CNN with limited labeled data, you should:
AFreeze early layers (which encode general features), train only the new task-specific output layers first, then optionally unfreeze deeper layers with a small learning rate
BRandomly reinitialize pretrained weights before fine-tuning

Q33Ensemble MethodsMultiple Choice
Extra-Trees differ from Random Forests in that:
AExtra-Trees subsample both instances and features at each split
BExtra-Trees use random thresholds rather than searching for the optimal threshold, making training faster
CExtra-Trees grow shallower trees to reduce variance

Q34CNNsMultiple Choice
"Same" padding ensures:
AOutput spatial dimensions equal input dimensions when stride=1
BThe same weights are used for all filter positions
CThe filter size equals the input size
DPadding value matches the input feature map mean
"Same" padding adds zeros so output height and width match input (for stride=1). "Valid" padding adds no padding, shrinking output by filter_size - 1 in each dimension.
Q35Dimensionality ReductionMultiple Choice
LLE (Locally Linear Embedding) is impractical for very large datasets because:
AIts O(dm²) complexity in the last step grows quadratically with instance count
BIt cannot handle more than 10 input features
CIt requires more memory than PCA for high-dimensional data
DIts manifold assumption requires spherical data distributions
LLE's m² term grows rapidly. For m=100,000 instances this is 10¹⁰ operations — prohibitively slow. LLE works well for small to medium datasets with nonlinear manifold structure.
Q36CNNsMultiple Choice

BThe vanishing gradient problem by providing a direct gradient path through identity shortcuts

Q37Decision TreesMultiple Choice
Decision Trees are called "white box" models because:
ATheir decision rules can be traced and explained — every prediction has a human-readable reason
BThey only work on linearly separable data
CThey output calibrated probabilities directly
DThey use convex optimization with provable convergence
From root to leaf, each split is a readable rule (e.g., petal_length <= 2.45). You can trace any prediction step by step. Neural networks and Random Forests are considered black boxes by comparison.
